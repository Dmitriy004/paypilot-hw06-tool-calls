## Реальна модель, виклики та ціна

Єдина модель у 203/203 LLM-спанах — **anthropic/claude-haiku-5.5** через OpenRouter; judge-викликів 0. 76 живих перевірених кроків, 160 `/chat` з історіями, 155 мок-відповідей моделі, 203 платні виклики на живих кроках. 631495 input tokens, 36003 output, 477820 cache read, 32947 cache write. Cache-токени — складові input, не додаткові input для подвійного рахунку.

За актуальним `/api/v1/models`: за 1M токенів input $0.10, output $0.50, cache read $0.01, cache write $0.125; великоконтекстний override тут не застосовується. Фактична сума **provider.cost_usd=$0.038970875** має пріоритет над відновленням по округлених токенах. Сума округлених `response.usage.cost_usd` — $0.038974, різниця $0.000003125 через округлення. Не використано тариф іншої моделі.

Сверка OpenRouter API: приріст usage за час ДЗ **$0.038970875**, точно співпав з 203 спанами. Перший after був неповним через lag, наступний зійшовся. Це звірка authenticated API, **не твердження про відвідування веб Billing-консолі**. Сирі фінансові snapshots лишено тільки локально: загальні витрати аккаунта, кредити й залишок балансу не публікуються, як і ключ/назва ключа/заголовки. Публічні підсумок сверки лише цього прогону й тариф: `provider-usage.json`.

S5 лише release: 5/5 cached кроків = $0.00154090, середнє $0.00030818; 5/5 uncached = $0.004426125, середнє $0.000885225; ratio **2.8724284509**. Обидві умови по 10 LLM-викликів, той самий набір/модель/крок; змінено лише defects D28. Перший виклик може бути cold, assertion стартує з другого.
